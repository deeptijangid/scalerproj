# Secure Messaging Platform

A simple real-time chat website inspired by Signal Messenger.

## Tech Stack

* Next.js
* TypeScript
* Python
* FastAPI
* SQLite
* WebSockets

## Project Structure

```text
secure-messaging-platform/
├── frontend/
├── backend/
└── README.md
```

## Running the Project

### Frontend

```bash
cd frontend
npm install
npm run dev
```

The frontend will run at:

```text
http://localhost:3000
```

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

The backend will run at:

```text
http://localhost:8000
```

This project was developed as a learning project to explore full-stack web development and real-time communication.
